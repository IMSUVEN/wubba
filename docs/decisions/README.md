# Decisions

Record significant technical and project decisions in this directory.

## When To Record

A decision is worth recording when:

- Reversing it later would be costly
- The reasoning is non-obvious and future sessions need to understand why
- Multiple alternatives were seriously considered
- It changes the default way contributors should extend or maintain the project

Not every small choice deserves a file. Record the decisions that shape how the
project grows.

## Format

Use one file per decision with the name `NNN-short-title.md`.

Each decision should capture:

- What was decided
- Why it was decided
- What alternatives were considered

Write for future readers who need to recover judgment quickly.
